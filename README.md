# Keyboard Ghosts

Keyboard Ghosts is a browser game you play with the Tab key. A haunted web page is dark, and your keyboard focus is the only light. Each ghost is a real accessibility barrier, such as a missing focus ring or a keyboard trap, and you repair it to bring the light back.

## Run

```
nvm use
npm install
npm run dev
```

Other commands: `npm run check`, `npm run build`, `npm test`, `npm run e2e`.
